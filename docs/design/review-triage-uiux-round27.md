# Round 27 triage: the composed prefix that converted a link failure, and the upgrade that proved nothing

Configuration: the same three bllm lanes against the round-26 HEAD. The two
headlines are both direct consequences of round-26's own edits — the
plugin-backend wrapper composed a prefix that destroyed the transport
family's anchored match (turning a link failure into a permanent red
banner), and the realtime onopen retires claims on evidence the proxy
architecture does not support. The convergence pattern held: lane A dropped
to seven low/medium geometry findings on two named seams (host-sheet adopt
order, missing coarse floors), and lane B found no new producers.

## Fixed in this wave

1. **A link failure keeps the browser's own words** (lane C, High):
   "Plugin backend request unavailable: Failed to fetch" had a prefix, the
   transport family rules are anchored whole-message, so the match failed
   and the failure became a reader-retired permanent banner that survived
   every poll. The wrapper now throws the raw browser text — the healing
   rewrite is what the reader sees anyway — and the failure keeps its
   machine scope and its reply lifetime.
2. **The direct fetch legs stamp their machine** (lane C, Medium): a bare
   TypeError was the one unscoped transport claim; the fork and
   terminal-command-run legs wrap it with the machine they were talking to,
   closing the gap between the changeset's per-machine promise and the
   commonest failure shape.
3. **onopen stops retiring claims** (lane B, Medium): the proxies accept the
   WebSocket upgrade first and bridge upstream second, so onopen proves the
   web process is alive — not that this machine's daemon answered anything.
   During a daemon restart it retracted the banner half a second after
   raising it, for the whole outage. The reads onopen fires are what may
   retire claims now.
4. **The hold branch and the expiry callback reset the whole schedule
   marker pair** (lane B, Low): a controller-side clear inside the 1.5s
   window could not reach the privates, and a re-raise inside the hold
   window inherited a spent gate.
5. **The dead link parameter** (lane C, Medium): noticeFromError's
   live-link suppression branch was unreachable — no caller can prove
   liveness — and its docstring described it as present behaviour. The
   parameter, the branch and NO_NOTICE are gone; the open seam is recorded
   as open.
6. **A third-party manifest proves nothing about PI WEB's link** (lane C,
   Low): the plugin-manifest fetch no longer reports reachability — an
   outside server could retire a page claim it has no say in.
7. **The floors and the twins** (lane A): the updates panel's Copy/Run
   buttons (a bare-template panel the earlier floor waves missed), the
   workspace trust row, and ProjectList's retry button take the coarse 44px
   floor; the machine row's label gets the complete ellipsis trio its
   workspace sibling has, and the dead flex declaration that never survived
   the adopt order is gone; ProjectDialog's button rule takes one class of
   specificity so font: inherit survives the adopted host sheet — the same
   fix its small.hint sibling already took.
8. **Dead code and stale citations** (lane C): the show variant's unread
   text field, the "sending" member no status mapper returns, the
   .workspace-label-base selector with no emitter, and the capability map's
   and machines-axis design's surviving MachineSwitcher citations.
