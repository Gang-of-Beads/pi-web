# Round 25 triage: the recovery that could not deliver, the plugin layer below the seam, and the floor the panels never got

Configuration: the same three bllm lanes against the round-24 HEAD. Lane C's
verdict is the first fully positive model audit — no seam bypass, all
gates comparing raw claims, the rail cascade honest — with the defects now
living in the residue of the fixes themselves and in the plugin layer the
fix waves never reached.

## Fixed in this wave

1. **The unknown banner's retraction is deliverable** (lanes B/C,
   Medium-High — the strongest finding of either round): the empty-record
   guard ran before the retraction, and after the boot read every recovery
   read answers empty, so the banner's own "Reconnect to read it again"
   could never clear it. The unknown flag describes the read, not the
   record: any successful read clears it, before the emptiness decision.
2. **The unread ring wears the unread colour** (lane C, Medium): round-23's
   "one purple motif" stopped at the halo; the composite's ring two rules
   below kept accent — the running colour — making "unread + terminal"
   render identically to "terminal". Purple now.
3. **The terminals refresh gets the selection guard** (lane B, Medium): the
   next sibling after health and runtime, same late-failure shape.
4. **The plugin-backend leg keeps its machine scope on failure** (lane B,
   Medium-Low): round-23's record claimed both fetch legs threw HttpError;
   only the fork and terminal legs did. Both plugin-backend throws are
   scoped now; the r23 erratum is recorded below.
5. **Two plugin panels get the floors the shell gives everything else**
   (lane A, Medium): workspace-tasks' buttons had no control height at all
   (≈31px on a phone), relays' refresh button pinned 32px with ≈24px
   document tabs. Both take control-height/touch floors with border-box.
6. **Classification and display read the fetch family the same way**
   (lane B, Low): the classification-side regex is anchored whole-message
   like the display side — a composed detail containing "Failed to fetch"
   no longer classifies as a page transport claim.
7. **Small truths** (lanes A/C): the two rail-width literal regressions are
   tokens again; the idle kind has its own declaration instead of leaning
   on the wrapper's [hidden]; the disabled opacity is the one disabled
   token (and the typeScale guard now sees the 0.-prefixed spelling); the
   never-matching [collapsed] selectors and the inventory rows citing the
   deleted switcher are gone; operation-model's line-number anchor is now a
   name that cannot rot; the banner hold timer is cleaned up on disconnect.
