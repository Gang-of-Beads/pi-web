Images and files attached in the composer but not yet sent are now kept in this browser, so a reload, closing Settings, or a phone closing the tab no longer loses them. They stay on the device that added them; the text you type still follows the session to every device. An attachment added while a new session was still starting no longer disappears when the session starts. Reload the page.
