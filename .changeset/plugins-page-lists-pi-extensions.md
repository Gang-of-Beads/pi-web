Settings → PI WEB Plugins also lists the installed Pi packages that have no PI WEB part, under a **Pi extensions** heading: their name, source and scope, read-only. Before, a package such as a web-search extension appeared nowhere on that page, as if it were not installed. Install, update or remove them in Settings → Pi Packages as before.
