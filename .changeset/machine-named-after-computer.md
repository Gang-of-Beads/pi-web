The machine PI WEB runs on is now named after the computer (its host name, such as "Studio-Mac") instead of "Local", wherever machines are listed and in the path at the top. Rename it in Settings → Machines; the new name is kept on that machine, so every device browsing it sees the same name. Restart the web service to pick this up.
