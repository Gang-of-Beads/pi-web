A link to a workspace now says where it lands. In the wide layout, the address names the session it opened, so a reload or a shared link shows the same conversation; switching machines or opening a terminal still leaves your previous place one Back away. On a phone or other touch screen it shows the workspace's session list without quietly loading the latest conversation behind it, which made large sessions slow to land. A browser reload picks this up.
