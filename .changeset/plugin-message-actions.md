Browser plugins can put a button on transcript messages with the new `messageActions` contribution. The button sits left of Copy in the same box, on user or assistant messages with words in them, and receives the message's text (what Copy takes) with its machine, session and folder. A plugin can show the button's live state, such as pressed while something plays, and a failing button tells the reader instead of breaking the message.
