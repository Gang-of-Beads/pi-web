Settings → Plugins tells the truth about a plugin. A plugin that failed to load in this browser says so on its card, with the reason. When a toggle cannot be saved, the box goes back to the plugin's real state. A config file PI WEB may not write is reported in a sentence that names the file and how to fix it, instead of a bare `EACCES`. Restart the web service to pick it up.
