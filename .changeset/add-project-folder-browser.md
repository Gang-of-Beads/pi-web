Browse folders in **Add project**: the dialog opens on the selected machine's home folder, shows the current folder's path as clickable steps, opens a subfolder with one tap, and adds the current folder. **New folder** names a folder that is created only when the project is added. Folders that cannot be read, that do not answer in time, or that hold more subfolders than the list shows say so. Typing a path stays available behind the pencil beside the path, and every listing and the final add stay on the machine the dialog was opened for.
