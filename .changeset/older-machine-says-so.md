An action a machine is too old to have now says so: "This machine runs an older PI WEB that cannot do this yet. Update PI WEB there and restart its session daemon." It used to show a parse error ("Unexpected token <") or a bare "Not Found", for example when renaming a shell on a machine that runs an earlier release. Restart the session daemon and the web service.
