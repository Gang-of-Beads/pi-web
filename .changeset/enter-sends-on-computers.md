When the main pointer is a mouse or trackpad, Enter sends and Shift+Enter starts a new line at any window size or zoom; a narrow or zoomed-in computer window no longer turns Enter into a new line. Where the main pointer is a touch screen, Enter keeps starting a new line, because a touch keyboard has no Shift+Enter. An Enter Key Behavior chosen in Settings → Keyboard still applies.
