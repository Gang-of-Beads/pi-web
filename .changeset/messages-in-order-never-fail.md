A message never fails any more. It reads "Sending…" until the machine has it, and is sent again by itself, with the same identity, until it arrives - there is no "Not received", no Retry and no Discard. Everything a browser asks a session to do - messages, take-backs, slash commands and `!` commands - goes in order, in batches: what waited while the machine was not answering leaves in one request, the machine runs it in order and stops at the first thing it cannot run, and nothing runs twice. Sending continues in the background when you leave the session, across a reload, and from any tab of the same browser. A message still waiting can be taken back at once, its words back in the composer; one the machine already has is taken back by the machine. A slash command's result that needs the page waits until you return to its session. Notes about one message ("Already with the agent", "Not sent: …") show under that message instead of on the top row. The top row now says "Trying to sync with <machine>…" only when something sent to that machine has gone unconfirmed, and "Syncing with <machine>…" when the page knows it missed something and the fetch takes more than a second; a list drawn from memory no longer says "Syncing…". A message's time is the moment the agent got it; a waiting message shows no clock. The session daemon must be restarted, and pages and machines updated together: the old single-message routes are gone.
