Let an extension dialog carry the decision it is asking about. Titles and messages were bounded like the labels a user clicks (1,000 characters), so a dialog whose body is genuinely long — a goal proposal, a migration plan — was rejected outright, even though the card is built to render exactly that shape by splitting the first line into the heading and scrolling the rest. Prose now has its own, larger bound; option labels and placeholders keep the tight one.
