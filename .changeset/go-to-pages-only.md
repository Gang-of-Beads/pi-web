Go to lists the pages only: Sessions and Chat are gone from it, since the grid key opens the session list and the way back returns to the chat. On the wide layout the page column beside the chat has a bar naming its page, and the chat bar's Go to key opens the list inside that column, expanding it first when collapsed; a second press or Escape closes it, and picking a page changes only that column. The chat title no longer repeats the page name there. Every bar and dialog key now looks the same: one 36px box with an 18px glyph, reachable as 44px on a touch screen, and a sheet dropping over the bar puts its key exactly on the one that opened it. The session list's header is the same height as the chat bar.
