The button that returns you to the newest message appears when the transcript grows, not only when you scroll. A reply that grew the page produced no scroll event, so a reader who stopped following ended up four screens from the newest message with no way back.

The drawer's section buttons round to the radius scale instead of being pills, matching the controls around them.

Messages carry an identity, so a message delivered twice is drawn once.
