PI WEB installs on Windows. `pi-web install` registers the session daemon and the web server as per-user scheduled tasks, named after your Windows account so each account on a PC gets its own, that start when you sign in, run without a console window, restart after a failure and write their logs to `~/.pi-web/logs`, with no administrator rights. `uninstall`, `start`, `stop`, `restart`, `status`, `logs`, `doctor` and `version` work there too; a restart or uninstall started from a PI WEB terminal finishes in a short-lived scheduled task. A new PowerShell installer (`irm https://raw.githubusercontent.com/Gang-of-Beads/pi-web/main/install.ps1 | iex`) checks the requirements, installs the package and runs `pi-web install`. Restarting from the Updates page restarts both services there through a short-lived scheduled task, and answers with an error when the PI WEB tasks are not installed or that task could not be started; the page offers no separate web restart there, since it would stop the session daemon too. Applying an update from the browser is not available on Windows yet, and a saved update command is not offered there. A config file saved with a byte order mark, as Windows PowerShell 5.1 writes it, is now read instead of rejected as invalid JSON.
