On a phone, the Navigate page's header is now the path and the Go to key, the same shape as a chat's header, so a project's name is no longer cut short. Go to is there with or without a chosen project and gains a Settings line, which is how the phone reaches Settings. The grid mark that did nothing when there was nowhere to go back to is gone, and so are the full page reload key and the "Full page reload" action: lists and sessions refresh by themselves. Reload the page to pick this up.
