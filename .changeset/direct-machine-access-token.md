A machine that requires an access token can be added with **This browser**. Paste the token in the Add machine dialog; the page then sends it in the path of every request to that machine, including WebSockets, images, file previews and plugin modules. Before, such a machine only worked with **This server**, and one forced onto **This browser** showed "requires an access token" from time to time and lost its live updates.
