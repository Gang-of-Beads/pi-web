Every New session entry says where the session will start before you press it: "New session in <project>" when the list is narrowed to a project, and "New session… Choose a project" under All projects, with no project open, or when browsing another machine; it no longer starts silently in the project selected before. Choosing asks in a dialog that offers a new project first and lists the machine's projects as the Projects page does, the one used last first; a new project opens its first session itself. A new session is created on the machine as soon as it opens, so its model, thinking level and commands are there at once, and its title and empty page name its project and machine. An empty session is listed "not started" and can be archived like any other; restoring it brings the empty session back. Choosing a machine on the Navigate page switches to it.
