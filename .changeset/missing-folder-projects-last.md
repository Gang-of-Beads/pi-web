A project whose folder no longer exists is now listed after the others, with its second line reading "Folder missing" before the path, in the Projects list and the project menu of the path at the top; in the Projects list it is also greyed. It stays listed in case the folder comes back; "Close project" in its ⋯ menu removes it from PI WEB without touching anything on disk. Before, it looked like any other project, and choosing it only showed a red message. Restart the web service to pick it up.
