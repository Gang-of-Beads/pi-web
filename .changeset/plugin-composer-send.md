A plugin's composer control can press Send for the session it belongs to: the draft on screen goes exactly as the Send button would send it, and only while that session is on screen. Such a message shows "Sent with <plugin name>" in its details on every device and after a reload; a message you send with the Send button carries no mark, even when a plugin wrote the draft.
