A shell tab on the Terminal page can be renamed. Double-click it (hold it on a phone) or press F2 to edit the name in place, or open its ⋯ menu and choose Rename…; Enter or leaving the field saves, Escape keeps the old name. The name is kept with the shell, so another device shows it the next time it lists the shells. Restart the session daemon and the web service.
