On a phone, Back from a session you picked in the Navigate list returns to that list and stays there; Back again returns to the session you were in before. It used to skip the list, show it for a moment while the earlier session loaded, and then jump into that session. A session being opened by Back, Forward or a link now shows "Opening session…" instead of the list, and going back to a page with no session no longer leaves the last one selected.
