Draw no scrollbar on any page that scrolls as a whole: the session list, the pages plugins draw, Settings, Go to, the session tree, Clean up sessions and the full-screen sheets, as the conversation already did. On Windows, Linux and Macs set to always show scrollbars the rail pulled each page's right edge in from the bar above it; on phones the scroll indicator no longer crosses the content. Wheel, trackpad, touch and keyboard scrolling are unchanged; code blocks, tables and other boxes inside a page keep their scrollbars, and Windows high-contrast mode keeps every scrollbar. A session list column narrowed below one tile's width now fits its tiles instead of cutting off their right edge.
