Files can be dropped anywhere in the chat, not only on the message box: while files are dragged over the chat a dashed frame says "Drop files to attach", and the dropped files join the message's attachments as they would from the box. A file dropped anywhere else on the page no longer opens in the browser in place of PI WEB. Restart the web service to pick it up.
