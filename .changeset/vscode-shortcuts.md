The desktop keys now follow VS Code: ⌘P (Ctrl+P) opens the session switcher, as before, and ⌘⇧P (Ctrl+Shift+P) opens the action palette instead of ⌘K. Each search box shows its key, for example "Search sessions (⌘+P)". Firefox keeps ⌘⇧P for a private window, so there pick another key under Settings → Shortcuts. Restart the web service to pick it up.
