A project you open is trusted unless you say otherwise: in the Add project dialog, **Trust this project** starts checked for a folder with no saved trust decision, and adding the project saves the choice. Each project's **⋯** menu has a **Trusted** switch, as each workspace's menu does, and a workspace's menu opened with a long press or a right-click now shows its trust instead of an unset switch.
