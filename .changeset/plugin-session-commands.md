A plugin page can run the extension commands its package declares (`sessionCommands`) in the session on screen and hear how it went; the plugin's card in Settings lists those commands. Built-in commands (even when an extension registers the same name), skills, prompt templates and undeclared commands are refused. While the machine holds such a command before running it, for example during a compaction, it is not shown as your queued message, and Stop or Clear queue does not put it in your composer.
