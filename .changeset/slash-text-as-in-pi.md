Text that starts with `/` is read as pi reads it. Only an exact pi built-in command, its bare name or its name with the words pi takes after it, runs as a command; everything else is sent as an ordinary message with its normal numbering, queue place and own Take back, and pi decides when the message reaches it: a registered extension command, skill or prompt template runs, and any other text, such as a path like `/home/me/notes.txt`, a name that is no command, or a built-in followed by words pi does not take, goes to the model. Before, such text without attachments was handled as a command (only `/new` followed by words already went as a message): an unknown name answered "Unknown command" and nothing was sent, `/reload now` reloaded the session, `/settings please` was refused, and `/logout openai` signed out of that provider at once. Typed extension commands, skills and templates now show as ordinary message rows instead of command rows. A skill message shows as one message with its arguments and attachments, and Edit and send again puts the `/skill:` name back in front of its words. Built-in commands that only work in pi's terminal stay unavailable instead of reaching the model.
