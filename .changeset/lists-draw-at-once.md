The Navigate session list and session search now draw the sessions this browser saw last time as soon as the page opens, instead of waiting for the machine to answer, and replace them with the machine's answer when it arrives. In Navigate, sessions that move, appear or leave because of the server now slide or fade into place briefly; your own actions, searches and scope changes still apply at once, and nothing moves when the system asks for reduced motion. The remembered list stays in this browser for up to a week. Reload the page to pick it up.
