What a session is running reads as one status line. The chip strip above the activity dock ("Background · 404 finished", "Git · main") is gone, along with the unstyled background-task list it opened over the transcript. Background work now rides the dock's own line in every state ("receiving response · 1 background run"), stays on the dock while a question card is open, and is never the part a long label ellipsizes away. The background-run count was never shown before because the app did not pass plugin notes to the transcript; it does now.
