The Updates page has a **Downloads → On mobile data** row. It defaults to asking before an update downloads on mobile data; **Download automatically** skips the question and **Only on Wi-Fi** labels the Update button with the connection it will use. Wi-Fi and wired connections never ask. The choice is kept in that device's browser storage, so it follows the phone rather than the machine.
